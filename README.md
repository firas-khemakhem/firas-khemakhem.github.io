# firas-khemakhem.github.io

Source for my personal portfolio, published with GitHub Pages.

**Live site:** https://firas-khemakhem.github.io

The site is a single static HTML page with no framework or build step. It positions me for DevOps/Platform roles: CI/CD, Docker, release delivery and Kubernetes CI, backed by C++/Python automotive software experience, public projects, product-ownership work and contact links.

## Files

- `index.html` — the portfolio
- `assets/firas-khemakhem-cv.pdf` — downloadable CV
- `favicon.ico`, `apple-touch-icon.png`, `og-image.png` — icons and social preview
- `robots.txt`, `sitemap.xml` — search metadata
